feat(system): Introduce LOGOS architecture for advanced prompt and workflow management

This commit introduces the LOGOS system, a comprehensive, multi-layered architecture for managing Gemini CLI interactions, prompts, and automated workflows. This new structure replaces the previous flat `GEMINI.md` file with a more robust and scalable system.

Key changes include:
- **LOGOS Core:** A four-layered architecture (Constitution, Arsenal, Factory, Meta) to standardize operations, provide expert prompts, automate complex tasks, and enable self-improvement.
- **Prompt Library (Arsenal):** A structured library of specialized prompts for tasks like code analysis, generation, refactoring, and project management, each with a defined expert persona.
- **Workflows (Factory):** Introduction of automated, multi-step workflows that chain prompts together to perform complex tasks like `full_refactor_and_test`.
- **Refactoring:** Significant refactoring across the codebase to improve modularity, error handling, and align with the new LOGOS principles. Key refactored modules include `cv_analyzer`, `reporting`, and `config`.
- **Environment & Tooling:** Updated the Docker sandbox to use NVM for Node.js management and enhanced the Gemini CLI settings with new capabilities.

This architectural evolution aims to enhance the system's consistency, efficiency, and scalability, laying the groundwork for more advanced AI-driven development capabilities.
